Giriş yapın

Değişiklikler doğrudan GitHub deposuna kaydedilir. Giriş için bu depoya yazma izni olan bir GitHub erişim anahtarı gerekir.

Depo ayarları

Erişim anahtarı nasıl oluşturulur?
  1. GitHub’da Settings → Developer settings → Personal access tokens → Fine-grained tokens sayfasına gidin.
  2. Generate new token deyin, bir ad ve son kullanma tarihi verin.
  3. Repository access bölümünde Only select repositories seçip yalnızca site deposunu işaretleyin.
  4. Permissions → Repository permissions → Contents iznini Read and write yapın.
  5. Oluşan anahtarı kopyalayıp yukarıya yapıştırın. Anahtarı kimseyle paylaşmayın.
